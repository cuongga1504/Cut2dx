Optimal2DX for .NET / C# • Phiên bản 4.0

Hướng dẫn sử dụng Thư viện Optimal2DX

Tài liệu hướng dẫn lập trình toàn diện, phân tích thuật toán tối ưu hóa cắt tấm 2D (2D Cutting Stock & Rectangular Nesting) bằng ngôn ngữ C#.

1. Giới thiệu tổng quan

Optimal2DX (tiền thân là optimal2dx.dll) là thư viện thuật toán công nghiệp hàng đầu chuyên giải quyết bài toán Cắt tối ưu 2D (2D Rectangular Nesting / Cutting Stock Problem). Thư viện giúp các nhà máy và xưởng sản xuất gỗ tấm, kính xây dựng, tôn cuộn, cơ khí kim loại tấm, v.v. bố trí các chi tiết cần cắt lên các tấm phôi nguyên liệu có sẵn sao cho tối đa hóa diện tích sử dụng và giảm thiểu tối đa phần trăm phế liệu dư thừa.

💡 Điểm nổi bật của bản C# tái lập trình:
  • Mã nguồn C# thuần túy (Pure C# .NET 10 / .NET Core), tương thích 100% API của DLL 32-bit gốc.
  • Không còn phụ thuộc vào đăng ký COM (regsvr32), không lo lỗi môi trường Win32/x64.
  • Tốc độ tính toán siêu nhanh, hỗ trợ đa luồng và dễ dàng nhúng vào Console, WinForms, WPF, Web API hoặc ASP.NET Core.

2. Các loại thuật toán cắt 2D

Thư viện cung cấp 3 phương thức tối ưu hóa chuyên biệt phù hợp cho từng loại máy móc cắt:

✂️ 1. Guillotine Cuttings

Phương thức: StartGuillotine()

Cắt xẻ thẳng hoàn toàn từ mép này sang mép kia của tấm phôi (song song với các trục tọa độ). Phù hợp cho máy cưa bàn trượt, máy cắt kính, cưa panel saw công nghiệp.

🧩 2. Non-Guillotine (Nested)

Phương thức: StartNested()

Xếp lồng chi tiết tự do theo thuật toán Maximal Rectangles. Không yêu cầu đường cưa phải chạy suốt mép. Thích hợp cho máy cắt Laser, Plasma CNC, hoặc máy cắt tia nước (Waterjet).

📐 3. Multi-Stages Guillotine

Phương thức: StartMultiStages()

Cắt Guillotine phân tầng nghiêm ngặt (2 tầng, 3 tầng, hoặc N tầng). Trong mỗi tầng chỉ được phép cắt theo một chiều (Dọc hoặc Ngang). Phù hợp dây chuyền cắt phôi tự động.

3. Cài đặt & Tích hợp vào dự án C# / .NET

Bạn có thể tham chiếu trực tiếp project hoặc file Optimal2DX.dll vào ứng dụng C# của mình:

// 1. Thêm tham chiếu thư viện vào file .csproj:
<ItemGroup>
    <ProjectReference Include="..\Optimal2DX\Optimal2DX.csproj" />
</ItemGroup>

// 2. Sử dụng namespace trong code C#:
using Optimal2DX;
using Optimal2DX.Models;

Khởi tạo đối tượng tối ưu hóa:

var opt = new Optimization2DX();
Console.WriteLine($"Phiên bản: {opt.Version}");

4. Quy trình 5 bước tối ưu hóa

Toàn bộ quá trình tối ưu hóa vận hành theo 5 bước tuần tự chuẩn mực:

1 Khai báo chi tiết cần cắt (Demand Pieces / Parts)

Thiết lập tổng số lượng chi tiết và kích thước từng tấm cần cắt:

// Tổng số lượng chi tiết cần cắt là 14 tấm:
opt.NumberOfDemandPieces = 14;

// SetDemandPiece(Index, Length, Width, CanRotate, ExternalID, Priority)
opt.SetDemandPiece(0, 60, 40, 1, 0, 0); // Tấm #0: 60x40, cho phép xoay (1), mã ID = 0

2 Khai báo các tấm nguyên liệu có sẵn trong kho (Stock / Repository)

Khai báo kích thước các tấm phôi và các mép cắt tỉa hư hỏng (nếu có):

// Kho có 3 tấm phôi:
opt.NumberOfRepositoryPieces = 3;

// SetRepositoryPiece(Index, Length, Width, TrimTop, TrimLeft, TrimBottom, TrimRight, ExternalID, Priority, NumberOfHoles)
opt.SetRepositoryPiece(0, 300, 200, 0, 0, 0, 0, 0, 0, 0); // Tấm 300x200 mm
opt.SetRepositoryPiece(1, 200, 200, 0, 0, 0, 0, 1, 0, 0); // Tấm 200x200 mm
opt.SetRepositoryPiece(2, 300, 250, 0, 0, 0, 0, 2, 0, 0); // Tấm 300x250 mm

3 Thiết lập các tham số tối ưu (Parameters)

opt.BladeWidth = 0;          // Bề dày mạch cưa hao hụt khi cắt (kerf) = 0
opt.OptimizationLevel = 50;  // Cấp độ giải thuật di truyền (1 - 100)
opt.RandomSeed = 1;          // Seed ngẫu nhiên để tái lặp chính xác kết quả
opt.MinimalUsefulSize = 20;  // Kích thước tối thiểu để tính phế liệu tái sử dụng

4 Kích hoạt thuật toán tối ưu hóa

// Chọn 1 trong 3 phương thức cắt:
opt.StartGuillotine();   // Cắt thẳng Guillotine
// opt.StartNested();    // hoặc Cắt xếp lồng Laser/Plasma
// opt.StartMultiStages();// hoặc Cắt phân tầng

5 Trích xuất kết quả

// 1. Số lượng tấm kho đã dùng:
int totalSheets = opt.TotalNumberOfUtilizedRepositoryPieces;

// 2. Lặp qua từng tấm để lấy thông tin chi tiết:
for (int sheet = 0; sheet < totalSheets; sheet++)
{
    // Tỷ lệ diện tích hữu ích che phủ (%):
    opt.SurfaceCovered(sheet, out double surfCovered, out int repIndex, out int repId);

    // Lấy danh sách các nhát cắt:
    opt.NumberOfCuttings(sheet, out int noCuts, out _, out _);
    for (int i = 0; i < noCuts; i++) {
        opt.GetCut(sheet, i, out int tx, out int ty, out int bx, out int by, out int thick, out _, out _);
        // Vẽ đường cắt từ (tx, ty) đến (bx, by)
    }

    // Lấy vị trí các chi tiết đã xếp lên tấm:
    opt.NumberOfUtilizedDemandPieces(sheet, out int noPieces, out _, out _);
    for (int i = 0; i < noPieces; i++) {
        opt.GetUtilizedDemandPiece(sheet, i, out int tx, out int ty, out int bx, out int by, 
                                   out int rot, out _, out int demIdx, out _, out int demId);
        // Chi tiết nằm trong hình chữ nhật từ góc (tx, ty) tới (bx, by)
    }

    // Lấy các mảnh thừa phế liệu:
    opt.NumberOfWastePieces(sheet, out int noWastes, out _, out _);
    for (int i = 0; i < noWastes; i++) {
        opt.GetWastePiece(sheet, i, out int tx, out int ty, out int bx, out int by, out _, out _);
        // Tọa độ mảnh phế liệu (tx, ty) tới (bx, by)
    }
}

5. Tra cứu toàn bộ API (API Reference)

5.1. Bảng Thuộc tính (Properties)

Tên thuộc tính Kiểu dữ liệu Mô tả chi tiết
NumberOfDemandPieces int Số lượng chi tiết cần cắt. Thiết lập giá trị này sẽ cấp phát mảng dữ liệu chi tiết.
NumberOfRepositoryPieces int Số lượng tấm nguyên liệu trong kho. Thiết lập giá trị này sẽ cấp phát mảng tấm kho.
BladeWidth double Bề dày của mạch cưa / tia cắt (kerf). Cho phép số lẻ và tự động làm tròn đến 1 chữ số thập phân (ví dụ 3.2 mm). Mặc định: 0.
OptimizationLevel int Cấp độ tìm kiếm di truyền (1 đến 100). Càng cao thì thuật toán tìm nghiệm càng kỹ. Mặc định: 50.
RandomSeed int Seed khởi tạo bộ sinh ngẫu nhiên. Giữ nguyên seed sẽ cho ra kết quả sắp xếp giống hệt nhau. Mặc định: 1.
MinimalUsefulSize int Kích thước cạnh tối thiểu để một mảnh thừa được coi là "phế liệu có ích / tái sử dụng". Mảnh nhỏ hơn sẽ tính là "phế phẩm vụn" (Garbage).
MaximalCutLength int Giới hạn chiều dài tối đa của một đường cắt xẻ (phù hợp với giới hạn hành trình của máy cưa). 0 = không giới hạn.
FirstDirectionMultiStages int Hướng cắt đầu tiên trong chế độ Multi-Stages. 0 = Cắt ngang thành dải trước, 1 = Cắt dọc trước.
CutAllStripsFirst int Ưu tiên cắt toàn bộ các dải chính trước khi cắt chia nhỏ.
TotalNumberOfUtilizedRepositoryPieces int (get) Tổng số tấm nguyên liệu kho thực tế đã được sử dụng sau khi tối ưu.
TotalNumberOfUtilizedDemandPieces int (get) Tổng số chi tiết cần cắt đã được xếp thành công lên các tấm phôi.
TotalWaste double (get) Tổng diện tích phế liệu hao phí trên tất cả các tấm.
Version string (get) Phiên bản của thư viện (ví dụ "4.0.0 (C# Edition)").

5.2. Bảng Phương thức (Methods)

Phương thức Chức năng & Các tham số
SetDemandPiece(index, length, width, canRotate, externalId, priority) Khai báo thông số của một chi tiết cần cắt:
  • index: Thứ tự chi tiết (0 đến NumberOfDemandPieces - 1).
  • length, width: Chiều dài và chiều rộng (số nguyên > 0).
  • canRotate: 1 cho phép xoay 90 độ, 0 không được xoay (giữ hướng vân gỗ).
  • externalId: Mã định danh tùy chọn của bạn để theo dõi chi tiết.
  • priority: Mức độ ưu tiên cắt (0 = ưu tiên cao nhất).
SetRepositoryPiece(index, length, width, trimTop, trimLeft, trimBottom, trimRight, externalId, priority, numHoles) Khai báo thông số một tấm phôi trong kho:
  • length, width: Kích thước tấm phôi thô.
  • trimTop/Left/Bottom/Right: Bề rộng viền mép biên bị lỗi cần tỉa bỏ trước khi cắt.
  • externalId: Mã định danh tấm kho.
StartGuillotine() Chạy tối ưu hóa theo phương pháp cưa xẻ thẳng Guillotine (từ mép này sang mép kia).
StartNested() Chạy tối ưu hóa theo phương pháp xếp lồng tự do (Laser, Plasma, Tia nước).
StartMultiStages() Chạy tối ưu hóa theo phương pháp cắt Guillotine phân tầng (Multi-Stages).
SurfaceCovered(sheetIndex, out surfCovered, out repIndex, out repId) Lấy tỷ lệ diện tích che phủ hữu ích (0% - 100%) trên tấm có thứ tự sheetIndex.
GetCut(sheetIndex, cutIndex, out tx, out ty, out bx, out by, out thick, out repIndex, out repId) Lấy tọa độ đường cắt thứ cutIndex trên tấm:
  • (tx, ty): Tọa độ điểm đầu của nhát cắt.
  • (bx, by): Tọa độ điểm cuối của nhát cắt.
  • thick: Độ dày nhát cắt (bằng BladeWidth).
GetUtilizedDemandPiece(sheetIndex, pieceIndex, out tx, out ty, out bx, out by, out rot, out repIndex, out demIdx, out repId, out demId) Lấy tọa độ hình chữ nhật chứa chi tiết đặt trên tấm:
  • (tx, ty): Góc trên - trái.
  • (bx, by): Góc dưới - phải.
  • rot: 1 nếu chi tiết bị xoay 90°, 0 nếu giữ nguyên hướng.
  • demIdx, demId: Chỉ số và mã ID của chi tiết tương ứng.
GetWastePiece(sheetIndex, wasteIndex, out tx, out ty, out bx, out by, out repIndex, out repId) Lấy tọa độ hình chữ nhật của mảnh phế liệu dư thừa thứ wasteIndex.
SaveToFile(fileName, saveInput, saveParams, saveResults) Lưu toàn bộ dữ liệu bài toán và kết quả ra file văn bản (.txt) tương thích định dạng của Cut2DX.

6. Các thông số & Khái niệm kỹ thuật quan trọng

6.1. Hướng vân gỗ (Grain Direction) & Tham số CanRotate

Đối với các vật liệu như gỗ tự nhiên, gỗ công nghiệp phủ Melamine/Veneer, tấm inox xước bề mặt,... đều có một chiều hướng vân/thớ (Grain Direction) cố định. Để đảm bảo tính thẩm mỹ của sản phẩm nội thất và cơ lý tính của gỗ, các chi tiết cần được cắt đúng theo chiều vân thớ đã định sẵn.

🪵 Quy tắc 3 bước xử lý thớ gỗ (Theo chuẩn Cut2DX):
  1. Tấm kho (Repository Piece): Khai báo tấm nguyên liệu với chiều Length luôn song song với hướng thớ gỗ của tấm ván.
  2. Chi tiết cần cắt (Demand Piece): Cạnh nào bạn muốn song song với hướng thớ gỗ thì cạnh đó bắt buộc phải khai báo là Length. Cạnh còn lại vuông góc với thớ gỗ sẽ là Width.
  3. Khóa góc xoay (CanRotate = 0): Thiết lập CanRotate = 0 trong hàm SetDemandPiece để thuật toán không được phép xoay chi tiết 90 độ, đảm bảo chi tiết cắt ra luôn thuận vân thớ 100%.

Ví dụ thực tế từ tài liệu chính hãng:

  • Tấm ván kho: kích thước 3000 x 2000 mm, thớ gỗ chạy dọc theo chiều dài (3000).
  • Chi tiết cần cắt: kích thước 500 x 600 mm. Bạn muốn chiều thớ gỗ chạy dọc theo cạnh 600 mm.
  • Mã lệnh cấu hình chuẩn: 
    // Tấm kho: Length = 3000 (chiều vân), Width = 2000
opt.SetRepositoryPiece(0, 3000, 2000, 0, 0, 0, 0, 0, 0, 0);

// Chi tiết: Cạnh 600 song song thớ gỗ -> đưa vào làm Length, CanRotate = 0 (cấm xoay)
opt.SetDemandPiece(0, 600, 500, 0, 0, 0);

Trong ứng dụng WinForms: Cung cấp cột chọn "Thớ gỗ (Grain Direction)" cực kỳ trực quan với 4 chế độ:

  • Tự do (Không thớ): Cho phép xoay 90° (CanRotate = 1) để tiết kiệm diện tích tối đa.
  • Dọc (Theo Dài): Thớ gỗ chạy dọc cạnh Dài, tự động đặt CanRotate = 0.
  • Ngang (Theo Rộng): Thớ gỗ chạy dọc cạnh Rộng, tự động hoán đổi kích thước theo quy tắc Cut2DX và khóa xoay.
  • Cố định (Không xoay): Giữ nguyên hướng và kích thước ban đầu, không cho phép xoay.

6.2. Cắt tỉa mép (Trim Margins)

Các tấm phôi khi vận chuyển thường bị nứt, móp méo hoặc dập góc ở 4 mép biên:

  • Khai báo TrimTop, TrimLeft, TrimBottom, TrimRight trong hàm SetRepositoryPiece.
  • Thuật toán sẽ tự động trừ đi các dải mép lỗi này. Phần diện tích hữu dụng thực tế để bố trí chi tiết sẽ bắt đầu từ tọa độ (TrimLeft, TrimTop).

6.3. Bề dày mạch cắt (BladeWidth / Kerf)

Lưỡi cưa đĩa kim loại thường có bề dày từ 2.8 mm - 4.2 mm (ví dụ: 3.2 mm hoặc 3.5 mm). Khi cưa một đường, một lượng phôi sẽ bị nghiền thành mùn cưa và biến mất:

  • Thiết lập BladeWidth = 3.2 (cho phép số lẻ và tự động làm tròn đến 1 chữ số thập phân).
  • Thuật toán sẽ tự động cộng bù khoảng cách mạch cắt giữa tất cả các chi tiết liền kề để sau khi cưa, kích thước các tấm thành phẩm vẫn chuẩn xác 100%.

7. Ứng dụng WinForms trực quan (Optimal2DX.WinForms)

Dự án mẫu WinForms đã được lập trình sẵn tại thư mục E:\Cut2dx\Optimal2DX_CSharp\Optimal2DX.WinForms. Ứng dụng cung cấp giao diện đồ họa hoàn chỉnh với bảng vẽ GDI+ trực quan:

🖥️ Cách khởi chạy ứng dụng WinForms:

Mở PowerShell hoặc Command Prompt và chạy lệnh sau:

dotnet run --project "E:\Cut2dx\Optimal2DX_CSharp\Optimal2DX.WinForms\Optimal2DX.WinForms.csproj"

Hoặc nhấp đúp vào file thực thi: Optimal2DX.WinForms.exe

  • Gom nhóm các sơ đồ giống nhau (Pattern Grouping): Khi cắt hàng loạt hoặc khi số lượng chi tiết lớn, thuật toán sẽ sinh ra nhiều tấm có sơ đồ cắt hoàn toàn trùng khớp. Ứng dụng tự động phát hiện và gom nhóm các tấm này lại thành từng mẫu sơ đồ duy nhất (ví dụ: Sơ đồ #1 x 4 tấm, Sơ đồ #2 x 2 tấm), thợ cưa chỉ cần xem một bản vẽ là có thể cắt lặp lại số lượng lớn mà không sợ nhầm lẫn.
  • Bảng tổng hợp sơ đồ cắt (📊 Summary Patterns): Cung cấp bảng tổng quan toàn bộ các mẫu sơ đồ, số lượng tấm cần cắt theo từng mẫu, tỷ lệ che phủ và phế liệu. Nhấp đúp vào dòng để chuyển nhanh đến sơ đồ đó trên bản vẽ.
  • Con dấu số lượng cắt trên bản vẽ: Trên khung vẽ sơ đồ tấm, hiển thị con dấu nổi bật ✂ CẮT x{SL} TẤM ở góc trên cùng bên phải.
  • Nhập theo Quy cách & Số lượng (Quantity): Thay vì phải nhập từng dòng lặp lại, bạn chỉ cần nhập kích thước cùng Số lượng (SL) cho từng loại chi tiết (ví dụ: Cánh tủ số lượng 4) và từng loại tấm kho có sẵn. Hệ thống sẽ tự động nhân bản thành danh sách chi tiết cắt thực tế.
  • Quản lý Tên / Nhãn chi tiết (Labels): Cho phép đặt tên gợi nhớ cho từng chi tiết (ví dụ: Cánh tủ, Hông tủ trái, Mặt bàn,...) và từng tấm kho (ví dụ: Ván MDF chống ẩm, MFC An Cường Sồi,...).
  • Khung vẽ sơ đồ cắt (Canvas): Vẽ trực tiếp Tên chi tiết in đậm rõ ràng kèm kích thước và hướng thớ gỗ lên từng mảnh phôi, vẽ tên tấm kho lên khung bản vẽ, nền vân gỗ tự nhiên, các đường cắt cưa đỏ nét đứt cùng số thứ tự bước cắt.
  • Mô phỏng vân thớ gỗ trên từng chi tiết: Các chi tiết có cấu hình thớ gỗ sẽ được vẽ các đường vân sọc tinh tế cùng ký hiệu [⟷ Dọc] hoặc [↕ Ngang], chi tiết không vân hiển thị [⟳ Tự do] kèm góc xoay 0° hoặc 90°.
  • Nút nạp mẫu Cắt hàng loạt & Thớ gỗ: Tích hợp các nút mẫu trên thanh công cụ: "🪵 Ví dụ Thớ gỗ & Số lượng" và "🏭 Ví dụ Cắt hàng loạt (Gom sơ đồ)" để thử nghiệm ngay lập tức.
  • Nút chuyển sơ đồ / tấm (◀ / ▶): Dễ dàng lật trang xem từng mẫu sơ đồ hoặc chuyển sang chế độ xem từng tấm đơn lẻ qua checkbox "Gom sơ đồ giống nhau".
  • Xuất file báo cáo chi tiết: Nút "💾 Xuất file kết quả" xuất báo cáo đầy đủ bảng tổng hợp các mẫu sơ đồ kèm số lượng lặp lại, quy cách yêu cầu, danh sách chi tiết và nhát cắt.

8. Câu hỏi thường gặp (FAQ)

Q: Thuật toán có hỗ trợ số thập phân (số thực như 125.5 mm) không?

A: Hàm API nhận số nguyên (long/int). Để làm việc với số thực, bạn chỉ cần nhân tất cả các kích thước với 10 (để đơn vị thành 0.1 mm) hoặc 100 (để thành 0.01 mm). Ví dụ: 125.5 mm nhập là 1255.

Q: Làm thế nào để dừng thuật toán nếu thời gian tính toán quá lâu?

A: Gọi phương thức opt.Stop() từ một sự kiện nút bấm hoặc tiến trình khác. Thuật toán sẽ ngay lập tức trả về phương án tốt nhất đã tìm thấy được tại thời điểm đó.

Q: Tôi có cần cài đặt phần mềm khác hoặc đăng ký bản quyền không?

A: Không cần. Thư viện C# này hoạt động hoàn toàn độc lập, không cần đăng ký COM vào Windows Registry, chạy tốt trên mọi máy tính cài đặt .NET Core / .NET 6 trở lên.
