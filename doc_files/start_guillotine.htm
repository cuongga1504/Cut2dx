StartGuillotine


Name


            StartGuillotine


When to use it


            After all parameters have been set.

            Not during OnProgress or OnFinish events.


Prototype


            StartGuillotine


Explanations


            Starts the optimization process for guillotine cuts.

            The progress of the process can be see by checking the OnProgress event.


            At the end the OnFinish event is raised.


See Also:


            StartNested, StartMultiStages, Stop, OnProgress, OnFinish.
